BOpenliveSDK-AIR 1.0是用于哔哩哔哩直播开放平台项目接入的SDK。该SDK为使用AIR开发直播互动项目提供支持，遵循哔哩哔哩直播开放平台的文档规范，支持v2版本的平台接口。通过本SDK，开发者可以便捷地在AIR环境中集成与哔哩哔哩直播开放平台相关的核心能力，包括但不限于通信请求、信息接收等。

本文档介绍了BOpenliveSDK-AIR 1.0的各项功能及接口。对于普通用户，推荐查阅BOpenlivePipe 快速开始。
